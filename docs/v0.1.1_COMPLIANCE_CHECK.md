## 硬约束列表（4 条）

1. **玩家视觉**：必须用 `player.gd` 的 `_draw()` 画矩形（不依赖 .tscn 序列化）
2. **场景装饰视觉**：CanvasItem 下不要挂 ColorRect；若需装饰，用 Polygon2D 或 sprite
3. **菜单/UI 文字**：Label + 显式 `theme_override_fonts/font` 指定像素字体
4. **位置**：StaticBody2D / CharacterBody2D 不要手动写 position 在 .tscn 里——通过 instance 父节点覆盖，或在 `_ready()` 里设

## 修复中发现的新问题

### 🐛 BUG：v0.1.1 剑不可见

- `sword.tscn` v0.1.1 删了 ColorRect（按硬约束）
- `sword.gd` **没有 `_draw()` 函数** 画剑
- 结果：剑节点存在但**完全不可见**——用户能触发拾取（因为 collision shape 还在）但视觉上找不到剑在哪

**修复建议**（@general v0.1.2 一并做）：
```gdscript
# sword.gd 末尾加：
func _draw() -> void:
    if visible:
        # 灰色剑身 + 黄色剑柄
        draw_rect(Rect2(-4, -2, 8, 4), Color(0.7, 0.7, 0.75, 1))
        draw_rect(Rect2(2, -1, 2, 2), Color(1.0, 0.85, 0.2, 1))
```

或更简单：直接用 `draw_rect` 画一个深灰色矩形（R02 §6.4.3 一致）。

### 🧹 残留代码：`game.gd` 的 `ColorRect` 检查

```gdscript
# game.gd line 60-66
func on_player_get_sword() -> void:
    has_sword = true
    save_game()
    if player:
        var cr = player.get_node_or_null("ColorRect")
        if cr:
            cr.color = Color(0.5, 0.8, 1.0, 1.0)
```

按 R02 §6.4.3 玩家节点已删 ColorRect，这段代码是残留死代码（get_node_or_null 返回 null，无效）。但不影响功能（玩家变蓝由 `_draw()` + `has_sword` 控制）。

**清理建议**：可以删，但非阻塞。
