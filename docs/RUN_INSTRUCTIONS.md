# 样板启动说明

## 1. 预览版下载

下载 `builds/zelda-prototype.exe`（105MB）

## 2. 运行

Windows Surface Pro 8 上直接双击 `zelda-prototype.exe`

## 3. 操作

- **WASD** 或 **方向键**：四向移动
- 绿色墙和地板会阻挡移动（碰撞检测正常）
- 角色限制在 256×224 像素画面内
