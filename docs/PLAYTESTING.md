# Surface Pro 8 试玩说明

> 这是 P02（仅验收，不构建）任务下的配套文档。E01 已完成最小可运行版（`builds/zelda-prototype.exe`，105MB），现在请你下载到 Surface Pro 8 上试玩，把反馈带回给团队。

## 1. 下载

- 文件：`builds/zelda-prototype.exe`（约 105MB）
- 来源：`/home/ben/zelda-remake/builds/zelda-prototype.exe`（macmini02 服务器，需要通过你们常用的方式拉到本地，比如 scp / SFTP / 直接拷贝）
- **完整性提示**：传输时建议比对 sha256（`sha256sum zelda-prototype.exe` 在服务器端），避免大文件传输出错

## 2. 运行（Surface Pro 8 + Win11）

1. 拷贝到本地任意目录（桌面 / 下载都行）
2. 双击 `zelda-prototype.exe`
3. Windows SmartScreen 可能弹出"未识别的应用"警告——点"更多信息" → "仍要运行"
4. 第一次启动可能需要几秒钟加载 Godot runtime
5. 出现 256×224 的小窗口（按 §4 调整窗口大小）

## 3. 试玩清单（请逐项确认）

| 项 | 操作 | 期望 |
|---|---|---|
| 启动 | 双击 exe | 弹出小窗口，画面无报错 |
| 移动 | WASD / 方向键 | 角色（绿色色块）四向移动 |
| 碰撞 | 推向左墙 / 右墙 | 角色停住，不穿墙 |
| 边界 | 推到画面边缘 | 角色停在 256×224 边界内 |
| 关闭 | 关窗口 | 无残留进程 / 无崩溃 |

## 4. 试玩过程中可调整

- **窗口大小**：当前是 256×224 固定窗口（受限于占位图形分辨率）；如果画面太小看着累，告诉我，我让 @general 把窗口放大或加缩放选项
- **帧率**：默认 60 FPS；如果卡顿，告诉我具体场景
- **键位**：默认 WASD / 方向键；如果你想要手柄或不同键位，记下来

## 5. 反馈请记录这些点（越具体越好）

- 启动用了多久？有没有报错？
